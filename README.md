# Controle de Despesas com IA

App mobile para controle de despesas pessoais com ajuda de inteligência artificial (Google Gemini). Categorize despesas automaticamente, receba alertas e dicas de economia personalizadas.

## 🚀 Funcionalidades

✅ **Registro de Despesas** - Adicione despesas com descrição, valor, categoria e data

✅ **Categorização Automática com IA** - Google Gemini categoriza suas despesas automaticamente

✅ **Alertas Inteligentes** - Notificações quando você está próximo do orçamento mensal

✅ **Dicas de Economia** - IA analisa seus gastos e fornece dicas personalizadas

✅ **Análise Visual** - Gráficos e tabelas mostrando onde seu dinheiro está sendo gasto

✅ **Funciona Offline** - Dados salvos localmente, funciona sem internet

✅ **PWA (Progressive Web App)** - Instale como app no seu celular

✅ **Exportar/Importar Dados** - Backup dos seus dados em JSON

## 📱 Como Usar

### 1. Abrir o App

- Abra `index.html` em seu navegador
- Ou acesse em: https://seu-dominio.com

### 2. Configurar API Google Gemini

1. Vá em https://ai.google.dev/
2. Clique em "Get API Key"
3. Crie um novo projeto
4. Copie sua chave de API
5. No app, clique em ⚙️ (Configurações)
6. Cole a chave em "Chave API Google Gemini"
7. Defina seu orçamento mensal
8. Clique em "Salvar Configurações"

### 3. Adicionar Despesas

1. Clique em "➕ Adicionar"
2. Preencha:
   - **Descrição**: Ex: "Almoço no restaurante"
   - **Valor**: O valor da despesa
   - **Categoria**: Escolha manualmente ou deixe a IA escolher
   - **Data**: Data da despesa
3. Marque "Usar IA para categorizar automaticamente" para deixar a IA categorizar
4. Clique em "Adicionar Despesa"

### 4. Visualizar Análises

- Clique em "📊 Início" para ver resumo do mês
- Clique em "📈 Análise" para ver gráficos e tabelas
- Clique em "💡 Dicas" e depois em "Gerar Dicas com IA" para receber recomendações

## 🔧 Configurações

Clique em ⚙️ para acessar:

- **Chave API Google Gemini**: Necessária para usar IA
- **Orçamento Mensal**: Define seu limite de gastos
- **Alerta**: Percentual do orçamento para alertar você
- **Exportar/Importar**: Faça backup dos seus dados

## 🔐 Segurança

- Seus dados são salvos **apenas no seu dispositivo** (LocalStorage)
- A chave de API é armazenada localmente
- Nenhum dado é enviado para servidores nossos
- Apenas requisições para Google Gemini API são feitas
